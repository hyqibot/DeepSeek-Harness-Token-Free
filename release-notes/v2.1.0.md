# DeepSeek-Harness-Token-Free v2.1.0

## Features

- 设置页新增远程控制（配对、微信二维码、手机）与桌面工具（profile / 终端 / 更新 / 市场）
- Zero Token 一键授权走 webauth-ts（Node），授权成功后自动保活 Chrome 调试端口 9222
- 豆包、ChatGPT、Gemini、GLM 国际、Qwen 国际、Claude（CDP）聊天连不上 9222 时，立刻拉起调试浏览器再试一次；DeepSeek / Kimi / 通义国内 / GLM 国内不走这条路径

## Fixes

- DeepSeek 网页通道在 Node 24 上不再出现 `UND_ERR_INVALID_ARG`
- 网关 sidecar 启动失败会立刻报错，不再空等 `/health`
- 授权写完凭证后若 Playwright 卡住，会结束子进程并提示授权完成
- 聊天侧 CDP 重试会打回本机桌面接口，不再误连 `8088`
