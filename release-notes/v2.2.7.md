# DeepSeek-Harness-Token-Free v2.2.7

## Changes

- 设置页插件开关：修复 `include:` 前缀导致取消勾选后重启又自动启用的问题
- NICE 等自定义 provider：HYQi / Zero Token 同步改为只 patch 各自路由，删除后不再约 2 秒复活
- 自定义模型本地打开文件：Read only / Write 下 `Start-Process` 沙箱假成功会触发提权批准，不再误报「已打开」
- Zero-Token gateway vendor：pwsh/curl 与 repeat guard 等稳定性修复
