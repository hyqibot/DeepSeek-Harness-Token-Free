# DeepSeek-Harness-Token-Free v2.2.0

## Features

- 内置聊天模型 **HYQi**（Flash / Pro / Image / Video）：与 Zero-Token 共用同一张激活码，无需另填 API Key
- 设置页 HYQi 行显示「免token+工具链强化+非网页+无需Api」，编辑框密钥预置「已配置免token密钥，无需设置」
- 未激活时仍可在模型列表看到 HYQi；聊天会提示先到设置页激活 Zero-Token 网关

## Fixes

- 设置页点「模型」不再因 DOM 观察死循环卡死
- HYQi 网关超时不再把 HTML 504 原样送进聊天
- 许可证心跳把 504/非 JSON 当成网络故障，不再误判成未激活
- Windows 控制台不再把 Chromium crashpad 日志打成乱码
